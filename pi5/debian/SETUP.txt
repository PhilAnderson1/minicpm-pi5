MiniCPM Pi 5 installed. Installation does not start or restart the service.

Download the model (skip if already present):

  sudo curl -fL https://huggingface.co/openbmb/MiniCPM5-2B-GGUF/resolve/main/MiniCPM5-2B-Q4_K_M.gguf \
    -o /opt/minicpm-pi5/models/MiniCPM5-2B-Q4_K_M.gguf

Stop any other model server, then start:

  sudo systemctl start minicpm-pi5

Open http://localhost:8080 on the Pi.
Settings: /etc/default/minicpm-pi5
After an upgrade: sudo systemctl restart minicpm-pi5
